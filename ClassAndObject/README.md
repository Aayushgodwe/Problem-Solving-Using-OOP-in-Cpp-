# Class and Object in C++

## Practical Title

Implementation of Class and Object in C++.

## Aim

To understand and implement the concept of classes and objects in C++.

## Description

This program demonstrates the use of a class named `Student`.

The `Student` class contains:

- Data members for roll number and marks.
- A default constructor to initialize the data members.
- A `getData()` function to accept student details.
- A `display()` function to display student details.
- A `result()` function to check whether the student has passed or failed.
- A destructor.

## Concepts Used

- Class
- Object
- Data Members
- Member Functions
- Default Constructor
- Destructor
- Conditional Statements
- User Input and Output

## Working

1. An object of the `Student` class is created.
2. The user enters the roll number and marks.
3. The student details are displayed.
4. The program checks the marks.
5. If marks are greater than or equal to 40, the result is displayed as **Pass**.
6. Otherwise, the result is displayed as **Fail**.

## Conclusion

This practical demonstrates how classes and objects are used in C++ to organize data and functions. It also shows the use of constructors, member functions, conditional statements, and destructors.
