# Constructor Types in C++

## Practical Title
Implementation of Default, Parameterized, and Copy Constructors in C++.

## Description
This program demonstrates different types of constructors in C++.

## Constructors Used
1. Default Constructor
2. Parameterized Constructor
3. Copy Constructor

## Programming Language
C++

## How to Run

1. Compile the program:

g++ constructor.cpp -o constructor

2. Run the program:

./constructor

## Expected Output

The program displays student details initialized using different types of constructors.
