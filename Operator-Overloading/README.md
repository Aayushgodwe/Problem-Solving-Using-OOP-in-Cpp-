# Operator Overloading in C++

## 📌 Objective

* To understand the concept of operator overloading in C++.
* To implement default and parameterized constructors.
* To perform operations on objects using the overloaded `+` operator.

## 📖 Concept

Operator overloading is a feature of C++ that allows operators to work with user-defined objects. In this project, the `+` operator is overloaded to add the subscribers and views of two `channel` objects.

The project demonstrates the following concepts:

* Classes and Objects
* Default Constructor
* Parameterized Constructor
* Operator Overloading
* Member Functions

## ⚙️ Working

Two channel objects are created using the parameterized constructor. The overloaded `+` operator combines the subscribers and views of both objects and stores the result in another object.

A default constructor is also used to initialize an object with predefined values.

## 🎯 Learning Outcomes

* Understanding classes and objects in C++.
* Using default and parameterized constructors.
* Understanding the concept of operator overloading.
* Performing operations between objects using overloaded operators.
